# About Me

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;I'm <a href="https://www.instagram.com/e9artist" title="E9 Instagram Account" target="_blank">E9</a>, a solo guitarist who lives and plays in Detroit. I've been playing for <a href="#fn1" class="footnote-ref-text" id="ref1" title="Jump to footnote">19 years</a> and love blending <a href="https://en.wikipedia.org/wiki/Progressive_metal" title="Progressive metal - Wikipedia" target="_blank">prog</a>-inspired electric guitar with <a href="https://en.wikipedia.org/wiki/Electronica" title="Electronica - Wikipedia" target="_blank">electronica</a>, incorporating <a href="#fn3" class="footnote-ref-text" id="ref3" title="Jump to footnote">automated live looping</a> over backing tracks produced by me <small>(made possible by <a href="https://www.singlecellsoftware.com/" title="Caustic Music App - Single Cell Software" target="_blank">Caustic</a> and <a href="https://www.reaper.fm/" title="REAPER Website" target="_blank">REAPER</a>)</small>. My biggest influences are <a href="https://en.wikipedia.org/wiki/Dream_Theater" title="Dream Theater Wikipedia" target="_blank">Dream Theater</a> <small>(especially <a href="https://en.wikipedia.org/wiki/John_Petrucci" title="John Petrucci Wikipedia" target="_blank">John Petrucci</a>)</small>, <a href="https://en.wikipedia.org/wiki/Joe_Satriani" title="Joe Satriani Wikipedia" target="_blank">Joe Satriani</a>, and <a href="https://en.wikipedia.org/wiki/Orbital_(band)" title="Orbital Wikipedia" target="_blank">Orbital</a>. I like to call my genre of music <a href="#fn2" class="footnote-ref-text" id="ref2" title="Jump to footnote">progtronica</a> but I'm not sure how much it lives up to that descriptor. Regardless, I love the unusual combination of fast, technical electric guitar and robotic, yet hypnotic, <a href="https://en.wikipedia.org/wiki/Drum_machine" title="Drum machine - Wikipedia" target="_blank">programmed beats</a> and <a href="https://en.wikipedia.org/wiki/Synthesizer" title="Synthesizer - Wikipedia" target="_blank">synthesizers</a>.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;As stated elsewhere, this website is still very much under construction. I plan to add a lot more to each page, especially the <b>[Blog](/blog/)</b>, <b>[Music](/music/)</b>, <b>[Downloads](/downloads/)</b>, and <b>[Tools](/tools/)</b> pages. There's also currently a lot of redundancy on this site; eventually, the pages will narrow in scope<a href="#fn4" class="footnote-ref" id="ref4" title="Jump to footnote">1</a>. I tend to apologize for my longwindedness but since this is my site, I'll merely mention it as being one of my quirks <small>(hence, the footnotes)</small>. I can definitely see myself spending a lot of time writing on here, especially about my various electronics projects, so if you're interested in my work or art and enjoy lengthy reads and technical details about electronics and music <a href="https://en.wikipedia.org/wiki/Do_it_yourself" title="Do it yourself - Wikipedia" target="_blank">DIY</a> projects, you'll definitely wanna bookmark this site!
