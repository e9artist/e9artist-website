## My [Music](/music/)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Check out the <b>[Music](/music/)</b> page <small>(found up above in the Navbar)</small>. I've been working on a <a href="#fn4" class="footnote-ref-text" id="ref4" title="Jump to footnote">self-hosted music player</a>, streaming <small>192kbps 44.1kHz</small> mp3s residing in my <a href="https://www.dropbox.com/" title="Dropbox Website" target="_blank">Dropbox</a>. At some point, I will do a dedicated <b>[Blog](/blog/)</b> post about how to use the Player, the Playlist, and the Library but if you read the help text<a href="#fn5" class="footnote-ref" id="ref5" title="Jump to footnote">3</a> <small>(top of <b>[Music](/music/)</b> page)</small>, it is all rather intuitive. Basically, you can make a playlist of my songs and play them on my website. New mixes and songs will be topmost in the Library. Collections of songs <small>(called sections)</small> might be albums though they will most often just be a random collection. Sections will be listed in the Library chronologically with newest at the top. In fact, the default playlist will be updated to the latest section whenever a new one is uploaded <small>(which you can always go back to by hitting Reset in the Playlist area)</small>. Some less-used sections are collapsed by default but if you click the section title, it will toggle them open/closed. You can even search for specific songs or sections using the search bar.
- Folks looking for backing tracks to jam along to: search for <b>NO LEAD</b> songs
- Drummers looking for drumless songs to jam along to: search for <b>NO DRUMS with CLICK</b> songs
- Use ~ to exclude items from your search. For example, to show only "regular" songs, search for <b>~NO</b>

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;In addition to the Library being added to over time, the Player itself will be improved upon in terms of functionality and aesthetic. For example, currently you can shuffle the playlist and repeat single songs or the whole playlist. All these settings as well as your playlist should be saved by your browser! Note that not only is the player free to use but has <a href="#fn7" class="footnote-ref-text" id="ref7" title="Jump to footnote">NO ADS</a>.

## My [Downloads](/downloads/)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;This website will serve many purposes, not least of which are <b>archiving</b> and <b>sharing</b>. On the <b>[Downloads](/downloads/)</b> page you'll find both high-quality <a href="https://en.wikipedia.org/wiki/WAV" title="WAV - Waveform Audio File Format Wikipedia" target="_blank">WAV</a> versions of my songs as well as smaller <a href="https://en.wikipedia.org/wiki/MP3" title="MP3 Wikipedia" target="_blank">MP3</a> versions. There are many one-click options for downloading collections of songs as well as individual songs. The files are hosted on <a href="https://www.dropbox.com/" title="Dropbox Website" target="_blank">Dropbox</a> and, for now, I don't expect to hit any sort of bandwidth limits. Eventually, I will include many files besides songs including guitar tablature, <a href="https://www.arduino.cc/" title="Arduino Official Website" target="_blank">Arduino</a> sketches, and audio plugins <small>(all made by me)</small>. I've even got some programs that I've been coding up the last few weeks, in addition to coding up the website, that I'll probably offer for download soon on my website.

## My [Detroit Open Mic Calendar](/calendar/)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;I've been playing at various Detroit Open Mics over the last 3 years and in doing so, found a need to develop a centralized, easy-to-read listing of available open mics.<a href="#fn8" class="footnote-ref" id="ref8" title="Jump to footnote">4</a> My <a href="/calendar/"><b>Open Mic Calendar</b></a> is the result of that need and before having this website, it was shared all over Detroit through email chains. The calendar is simply a <a href="https://calendar.google.com/" title="Google Calendar Website" target="_blank">Google Calendar</a>, making it easy to share securely with folks. Not only can you view the calendar on my website directly but I also offer links to embed it or add it to one's own calendar app!

## My [Tools](/tools/)

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;On my <a href="/tools/"><b>Tools</b></a> page you'll find various web-based programs I've written <small>(for now, there's only one)</small>. These of course can be used by anyone but will mostly serve to be an online hub for me to use them. I've been developing a web-based text editor app that will soon be added to the Tools page <small>(I'm writing this blog post using it right now!)</small> and have some other apps for music creation, including a web-based version of my Android metronome app, that will be added eventually. I may make some of these tools available for download on the <a href="/downloads/"><b>Downloads</b></a> page as well, allowing folks to run them locally <small>(especially useful for things like the metronome app)</small>.
